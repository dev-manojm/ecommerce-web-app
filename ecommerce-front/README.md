# E-commerce Frontend

This React application uses Vite for development and production builds.

## Requirements

Use Node.js 22.12 or newer.

## Scripts

- `npm start` starts the development server on port 3000.
- `npm test` runs the Vitest suite.
- `npm run build` creates the production build in `build`.
- `npm run preview` serves the production build locally.

Set `REACT_APP_API_URL` in the environment or a local `.env` file to configure the backend URL.
